# v0.2 product scope

- Four independently buildable consoles with a common design system: AI-SDLC, Automation, Model Gateway and Sandbox Gateway.
- Automation case library: Web/API Workflow v2, immutable revisions, compile preview, owner-scoped execution history, result details and private artifacts. No test-plan scheduling.
- Real Web browser and HTTP API execution through Playwright inside controlled containers. Operator-registered target profiles support external targets; the bundled Northstar fixture provides deterministic, isolated sample data.
- AI-SDLC capabilities: DD-style requirement-implementation/historical-impact review, Markdown-to-Markdown test design, Markdown-to-Workflow compilation. Inputs and outputs are persisted. This is the portable Markdown/source mode, not the company's repository-wide DD integration or full original toolchain.
- When Model Gateway is in mock mode, capability outputs are explicit fixtures. Confirmed review findings require evidence validation; missing context remains visible. Upstream mode calls the configured API key provider.
- Supabase Storage is the single cloud object-storage backend. Logs, screenshots, Markdown, JSON, compiled scripts and reports have a persisted artifact catalog. No separate S3/MinIO deployment or S3 keypair is required.
- Demo initialization creates real editable cases. Execution records and success metrics come from actual runs, not fabricated history.

Management consoles display real provider/runtime settings. Runtime target/credential settings remain operator-controlled environment configuration; the public UI does not reveal secrets or mutate host Docker policy.
