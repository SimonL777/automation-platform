# Security

This release targets a trusted single-operator deployment. Protect the NAS ingress with authentication and TLS or a private network. Never expose the Docker API or socket to workloads. Container execution is not a hardened hostile-code service.

Keep API tokens, database credentials, provider keys and Supabase service-role keys in private environment configuration. Do not put secrets in issue reports. Report sensitive vulnerabilities privately through the maintainer profile before publishing exploit details.
